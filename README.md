Tutor Bot

Telegram-бот для взаимодействия репетитора с учениками и управления расписанием занятий.

Проект реализован на стадии MVP.

Возможности:

    Для ученика:

    - Регистрация по приглашению от репетитора
    - Просмотр ближайшего занятия
    - Просмотр расписания на неделю

    Для репетитора:

    - Просмотр списка учеников
    - Создание приглашений для регистрации учеников
    - Добавление занятий
    - Просмотр расписания на неделю

Использовал:

- Python 3.11
- aiogram 3
- SQLAlchemy
- SQLite
- asyncio


PS. Чтобы добавить учителя, в test_db.py вставляете telegram id пользователя,
которого хотите сделать учителем, до этого он должен быть зарегистрирован в боте как ученик.
Запускаете test_db.py, после чего в консоли результат выведется в формате: "Пользователь роль".
